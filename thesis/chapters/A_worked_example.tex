\chapter{One complete session}
\label{cha:worked-example}

This appendix walks through one run of the pipeline of \Cref{cha:design}. It is the \emph{regular} scenario (\Cref{sec:methodology-scenarios}: fixed macro targets -- roughly 2728~kcal, 124.8~g protein, 386.7~g carbohydrate, 75.8~g fat -- and no free-form request), planned by \texttt{gemini-3.7-flash} with the totaller and reflection loop active. It is illustrative, not a measurement; systematic figures belong to \Cref{cha:results}.

\Cref{lst:example-lookup} shows the lookup tool's response to a query for \texttt{rolled oats}, capped at one hit per source. It returns both channels at once -- a branded Polish Open Food Facts entry and a generic USDA one -- each with per-100~g nutrients and the source-prefixed \texttt{code} the agent must copy verbatim.

\lstinputlisting[caption={The lookup tool's JSON response for one query, one hit per source.},label={lst:example-lookup}]{listings/example_lookup.json}

\Cref{lst:example-plan} shows the breakfast meal as the model emitted it: each portion a reference (code, name, grams), with no nutrient values. This single meal mixes both catalogues -- Open Food Facts codes for the Polish branded oats, milk and honey, USDA codes for the generic chia, apple, walnuts and cinnamon.

\lstinputlisting[caption={The breakfast meal as the nutrition agent emitted it: references only, plus preparation instructions.},label={lst:example-plan}]{listings/example_plan.json}

Hydration resolves every reference to a database row and runs the totaller, filling in the numbers. \Cref{tab:example-breakfast-items} shows the same breakfast meal after that step; the output carries an equivalent breakdown for every meal.

Energy, protein and fat land within about a percent of target and carbohydrate within a few percent (\Cref{tab:example-totals}); the reflection loop reported no issues and ran zero refinement passes. Fiber sits well above target but is kept out of the macro error metrics as the nutrient most often missing from a crowd-sourced record (\Cref{sec:impl-missing-nutrients}).

The output also carries the plan's \emph{rationale} field (\Cref{fig:example-rationale}): an opening summary, dietary choices, and a supplementation section. The last is the kind of note the agent's prompt was extended to invite (\Cref{sec:impl-prompt-fixes}); here it flags vitamin~D as under-covered by food alone, citing the day's total of about 1.3~$\mu$g.
